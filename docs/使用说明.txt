DSH 桌宠（dsh-pet 独立版）使用说明
====================================
版本：v0.3.7-pack.14（DeepSeek Harness dsh-pet 插件的 Windows 独立打包版）
项目：github.com/PC2005-cloud/dsh-pet（MIT）

这是什么
--------
把 DeepSeek Harness 的 dsh-pet 插件（蓝色小女仆桌宠）打包成了独立的 Windows
程序：双击就能让桌宠住在桌面上，不需要打开 DeepSeek Harness。
另外加了：右键菜单精简 + 退出、AI 对话（直连 DeepSeek API）、本地对话记忆、
独立配置文件（和 DSH 各管各的）、大小调节、最小化到任务栏（托盘可恢复）、
随机动作、自动接入本机 DSH（只在 DSH 运行时接）、系统通知接管、开机自启自动配置。

启动 / 退出
-----------
1. 双击 DSH-Pet.exe —— 启动桌宠（约 2~5 秒后出现在桌面右上角）。
   启动后 DSH-Pet.exe 会在后台常驻（无窗口、不占任务栏），负责全屏隐藏、
   隐藏 DSH 自带那只桌宠、系统通知接管。
2. 再次双击 DSH-Pet.exe —— 问你是否退出，点“是”退出（后台常驻进程一起退）。
3. 右键桌宠 → “退出” —— 同样退出，并恢复系统通知设置。
4. 命令行：DSH-Pet.exe /stop 直接退出；/status 查看状态；/quit 同 /stop。

右键菜单
--------
- 查看余额   ：**只在接上 DSH 时才出现**（DSH 没运行时整项隐藏），点击以气泡显示余额
- 碎碎念     ：让桌宠立即说一句（接 DSH 时用它自己的模型，否则用直连 API）
- 对话       ：弹出输入框聊天，回答以气泡显示；多轮记忆
- 清空对话记忆：把这只桌宠的本地对话记忆清空
- 大小       ：小(360) / 标准(462) / 大(600) / 特大(760)，选完自动重建窗口
- 最小化到任务栏：桌宠窗口收起，任务栏通知区出现一只小图标；
                  右键那个图标 → “恢复桌宠” / “退出桌宠”，双击也能恢复
- 随机动作   ：随机播一个动画/动作
- 重载配置   ：重读 main-config.jsonc 并重建桌宠窗口
- 系统通知接管（已开/已关）：子菜单「开启接管 / 关闭接管」，随时切换，立即生效
- 动作       ：全部动画按分类列出，可逐一点播
- 退出       ：菜单最后一项；关闭桌宠并恢复系统原设置
（已按需求去掉：打开 DSH / 回到初始位置 / 速聊）

AI 对话与碎碎念（直连 DeepSeek API）
------------------------------------
- 独立版有**自己的一套配置**，和 DSH 插件完全不共用（DSH 改了也不影响这里）：
    C:\Users\<你的用户名>\.dsh\dsh-pet-standalone\
      · ai-config.json       API 地址 / 模型 / key
      · main-config.jsonc    大小、位置、显示开关
      · memory.json          对话记忆
  第一次启动会自动建目录：配置从 DSH 那份复制一份，之后两边各改各的。
- 首次启动会自动生成 ai-config.json（不需要手动填）：
  apiKey 优先取环境变量 DEEPSEEK_API_KEY，其次读
    C:\Users\<你的用户名>\.dsh\.credentials.yaml 里的 DEEPSEEK_API_KEY。
- 默认接口：https://apitiantian.com/v1（OpenAI 兼容），默认模型 deepseek-v4.1-flash。
- 想换模型/换 key：直接改 ai-config.json 的 model / baseURL / apiKey，重启桌宠生效。
  可用模型可用 curl https://apitiantian.com/v1/models 查看（需带 key）。
- 对话记忆保存在上面的 memory.json，只保留最近若干轮
  （插件配置 chatMemoryRounds，默认 5 轮）。
- 想完全不用 AI：把 ai-config.json 里 apiKey 清空即可（桌宠照常显示，只是不聊天）。

自动接入本机 DeepSeek Harness
----------------------------
- 桌宠启动后会找本机正在运行的 DeepSeek Harness（127.0.0.1 上它的本地服务），
  找到就自动“接上”：
    · 任务提示：DSH 里的任务进度/状态会以桌宠气泡播报（和原版一致）
    · 余额：接上 DSH 后右键菜单会多出“查看余额”，点击以气泡显示；DSH 没运行
      时这项自动隐藏（不再出现“余额暂不可用”的空提示）
    · 碎碎念 / 对话：优先用 DSH 的模型（省你自己的 API key、人设一致）
- DSH 关掉后自动断开，切回直连 API；余额状态显示为“DSH 未运行，余额暂不可用”。
- 强制不连接 DSH：启动前设环境变量 DSH_PET_NO_BRIDGE=1（调试用）。

系统通知接管
------------
- 桌宠运行期间会关掉 Windows 原生通知弹窗（任务栏右下角那种，微信/QQ/系统都算），
  任务提示改由桌宠气泡播报；退出桌宠时自动把你原来的通知设置恢复回去。
- 随时切换：右键桌宠 →「系统通知接管（已开/已关）」→ 开启接管 / 关闭接管，
  立即生效（会顺手把 Windows 推送服务重启一下，见下面说明）。
- 实现（全部可逆，退出时原样还原）：
    · 备份并改写 HKCU\Software\Microsoft\Windows\CurrentVersion\
      PushNotifications\ToastEnabled
    · 备份并改写 HKCU\Software\Microsoft\Windows\CurrentVersion\
      Notifications\Settings\NOC_GLOBAL_SETTING_TOASTS_ENABLED
    · 备份文件在程序目录 notify.state
    · **重启「Windows 推送通知用户服务」**（WpnUserService_xxx）—— 只改注册表
      的话系统还在用内存里的旧开关，弹窗照样出现，重启服务让它重新读取
- 如果桌宠被强行结束（任务管理器杀进程/蓝屏），通知可能仍处于关闭状态：
  重新启动一次桌宠再正常退出即可恢复；或手动到“设置 → 系统 → 通知”打开。
- 只接管“弹窗开关”，不读取其他应用的通知内容；微信/QQ 等应用自己的通知
  不会变成桌宠气泡（技术上需要应用商店打包身份才能读通知，普通 exe 做不到）。

开机自启（首次运行自动配置）
----------------------------
- 第一次运行 DSH-Pet.exe 时自动做两件事：
    · 若同目录没有 guard.ini，写入默认配置
    · 注册开机自启（HKCU\...\Run 的 DSH-Pet 项，指到本目录 DSH-Pet.exe --autostart）
- 手动开启：双击“设置开机自启.bat”，或 DSH-Pet.exe /install-autostart
- 手动取消：双击“取消开机自启.bat”，或 DSH-Pet.exe /uninstall-autostart
  （取消后程序不会再加回来，尊重你的选择）

打游戏 / 全屏时自动隐藏
----------------------
- 前台有“覆盖整块屏幕”的全屏应用时（全屏游戏、全屏视频、全屏演示、浏览器 F11），
  桌宠自动隐藏，退出全屏后恢复。普通最大化窗口（下面还有任务栏）不算全屏。
- 桌宠运行期间会始终隐藏 DeepSeek Harness 自带的那只桌宠，避免两只叠在一起；
  退出本桌宠后自动把那只恢复显示。
- 配置项在同目录 guard.ini，改完要先 /stop 再启动：
    hide_on_fullscreen    = 1     全屏自动隐藏
    also_hide_dsh_pet     = 1     全屏时连 DSH 那只一起藏
    hide_dsh_pet_always   = 1     运行期间始终隐藏 DSH 那只
    takeover_notifications= 1     接管系统通知
    poll_ms               = 500   检测间隔（200~5000）
    log                   = 1     写 guard.log

配置文件（大小 / 位置 / 显示开关）
----------------------------------
独立版单独一份（和 DSH 共用配置彻底分开）：
  C:\Users\<你的用户名>\.dsh\dsh-pet-standalone\main-config.jsonc
不存在就用程序内置默认配置（右上角、大小 462）；第一次运行会从 DSH 那份复制一份。
display 需要是 "desktop" 或 "both" 才会出现在桌面（设为 none 时本版也会兜底显示）。

体积与精简说明（v0.3.7-pack.14）
------------------------------
安装后约 324 MB，安装包约 151 MB（上一版分别是 418 MB / 206 MB）。做了这些精简：
  · 语言包只留 zh-CN 与 en-US（原来 50 个语言包占 47 MB，省 44 MB）
  · 第三方许可全文 LICENSES.chromium.html 压缩成 .gz 存放（省 17 MB，合规材料仍在）
  · 去掉桌宠用不到的组件：dxcompiler.dll / dxil.dll（WebGPU 用，约 26 MB）、
    vk_swiftshader.dll / vulkan-1.dll（软件 Vulkan 兜底，约 6 MB）
  · 安装包改用 zstd-19 压缩（比原来的 zip 小 27%）
如果哪台机器显卡驱动异常、桌宠窗口显示异常，可以把上一版 runtime\electron 里的
vk_swiftshader.dll / vulkan-1.dll 放回来再试。
安装器解压依赖系统自带 tar.exe（Windows 10 1803+ / Windows 11 都有）；如果没有，
装到一半会提示，改用便携版 zip 解压即可。

安装版（如果有 DSH-Pet-Setup.exe）
----------------------------------
- 双击安装，默认装到 %LOCALAPPDATA%\Programs\DSH-Pet（不需要管理员权限），
  自动创建开始菜单快捷方式和桌面图标，可选开机自启、装完自动启动。
- 卸载：设置 → 应用 → “DSH 桌宠” → 卸载；会先停掉桌宠、取消自启，再删文件。
  用户配置（.dsh\dsh-pet）默认保留，想清干净可手动删。
- 安装包/程序未做数字签名：首次运行 Windows 可能提示“已保护你的电脑”，
  点“更多信息 → 仍要运行”。这是 SmartScreen 对未签名程序的通用提示，
  不是杀毒软件报毒。

常见问题（卸载：默认会删除 .dsh\dsh-pet-standalone 内的全部配置与 API Key；想保留请用 Uninstall.exe /keepdata）
--------
- 双击没反应？看任务管理器里有没有 electron.exe（命令行含本目录
  app\lib\standalone.js）；卡住就先结束这些进程再试。
- 双击了但桌面没有宠物？常见原因是 DSH 侧把共用配置里的 display 改成了 none
  （%USERPROFILE%\.dsh\dsh-pet\main-config.jsonc）。本版已内置兜底：display 为
  none 时仍按桌面显示；如果还看不到，把该字段手动改回 "desktop" 再重启。
- 和 DSH 里的桌宠同时开？本版会自动把 DSH 那只隐藏；如果想彻底只留独立版，
  也可以在 DSH 设置里把该插件 display 改成 web。反之 DSH 里改配置不会影响独立版
  （独立版读 .dsh\dsh-pet-standalone\ 下的自己那份）。
- 大小改了没变？选完会重建宠物窗口，等 2~3 秒；想固定则改
  dsh-pet-standalone\main-config.jsonc 里的 size 再重启。
- 最小化后找不到了？在任务栏右下角的通知区（可能要点「显示隐藏的图标」^ 展开），
  图标提示为“DSH 桌宠（已最小化，右键可恢复）”，右键 → 恢复桌宠，双击也可以。
- 图标白底？本版已把 logo 的白底抠成透明（托盘/桌面快捷方式/程序都是用透明图标）。
- 余额气泡显示不全？余额文案里的档位已按你的要求改成“梁文峰/梁文谷”（原“峰/谷”），
  名字变长后气泡也放宽到宠物宽度的 0.8 倍并且强制单行，不会再折行/顶出白框。
- 对话/碎碎念失败？看 ai-config.json 的 apiKey 是否有效、模型名是否在
  /v1/models 列表里；网络需要能访问 apitiantian.com。
- 全屏没躲？看 guard.log 有没有 “fullscreen: ... -> hide pet”；窗口化全屏
  （没真正覆盖整屏）不触发。
- 这台电脑没装 DeepSeek Harness，能用吗？能。独立版自带 Electron 和全部素材，
  宠物照常显示（用程序内置默认配置：右上角、大小 462）。第一次启动会建
  %USERPROFILE%\.dsh\dsh-pet-standalone\ 目录；如果本机没有 DSH 那份配置，就不复制，
  直接用内置默认值（不会报错）。区别只有两点：①AI 对话/碎碎念要自己填 API key
  （没装 DSH 时借不到 .credentials.yaml，生成的 ai-config.json 里 apiKey 为空，
  点对话会提示去填）；②没有 DSH 桥接，余额/任务提示不可用。
- 端口：桌宠内部起本机服务（默认 127.0.0.1:3080，被占用自动顺延），只监听本机。
- 移动位置：整个文件夹可以随便挪（含中文路径），但目录结构别拆散；挪完重设
  开机自启（重新运行一次 /install-autostart），否则注册表还指向旧路径。
- 卸载（便携版）：/uninstall-autostart → /stop → 删整个文件夹；想连配置一起清，
  再删 %USERPROFILE%\.dsh\dsh-pet。

技术信息
--------
- 插件：dsh-pet@0.3.7（MIT）· 运行时：Electron 43.3.0（内置 runtime\electron\）
- 启动：electron.exe（ELECTRON_RUN_AS_NODE=1）跑 app\lib\standalone.js，
  DSH_PET_ELECTRON_PATH 指向内置 Electron，不需要联网下载运行时。
- 独立版补丁（app\lib\standalone.js / runtime\electron-helper\*.js）：
  · ctx.llm 换成直连 OpenAI 兼容接口（pet-ai 模块），支持流式
  · 新增本机路由 /chat/clear、/quit、/pet/size；/chat、/whisper、/balance 连接 DSH 时转发
  · 独立配置目录 dsh-pet-standalone（首次从 DSH 复制，之后互不影响）
  · 右键菜单终稿（去速聊、退出置底、大小、最小化）+ 随机动作
  · helper 独立 userData（dsh-pet-standalone-helper），不与 DSH 的 electron-helper 抢缓存
  · 托盘图标（Electron Tray）负责最小化后的恢复/退出
- 看门进程：DSH-Pet.exe 常驻，每 500ms 用 GetForegroundWindow + 显示器矩形
  判断全屏，命中时 ShowWindow(SW_HIDE)，离开后 SW_SHOWNA 恢复；同时隐藏
  DSH 那只桌宠窗口、接管通知开关（退出时全部还原）。

报时 / 待办 / 提示音（pack.7 新增）
────────────────────────────────────────
提示音目录（放在安装根目录下，程序自动调用）：
  <安装目录>\sounds\notify\   ← 外部通知（别人家 App 的 Windows 通知）被接管时播这里的音频
  <安装目录>\sounds\chime\    ← 整点/半点报时播这里的音频
  支持 mp3 / wav / ogg / m4a / flac / aac，多个文件会随机挑一个；没放文件时静音（不报错）。

整点报时：每小时 :00 与 :30 自动报时，桌宠会显示一个鲸鱼娘风格的时钟并持续约 1 分钟，
播放 sounds\chime 里的提示音；报时期间右键菜单照常可用。

待办提醒：右键菜单 → 待办 → 新增待办，填写标题/详情/日期/时间，可选重复：
  不重复 / 每天 / 每周（选星期）/ 每月（选日号）。
到点时：鲸鱼娘会放大到占满屏幕中央、播放「抽陀螺」动画，顶部弹出待办标题气泡，
  气泡上写着「点击这里 查看详情」——点气泡或鲸鱼娘即可看详情，按 Esc 或右上角 × 关闭。
超时提醒（例如电脑休眠错过了时间）会在 24 小时内补一次。
待办列表存在 %USERPROFILE%\.dsh\dsh-pet-standalone\todos.json，可备份/迁移。

系统通知接管开关：右键菜单 → 系统通知接管 → 开启/关闭接管。
  开启后 Windows 系统通知弹窗不再弹出（改成桌宠气泡 + sounds\notify 提示音）；
  关闭后立刻恢复系统弹窗。

可选：让 MSIX 通知监听器接管「别人家 App」的通知内容
────────────────────────────────────────
普通 exe 读不到其它应用的 Windows 通知内容（系统权限限制）。`.pet-build\msix\` 里是
一个已签名的 MSIX 通知监听器（只负责读通知，不碰桌宠本体）：
  1. 右键「01-管理员运行-信任证书并开启开发者模式.ps1」→ 以管理员身份运行（导入自签证书 + 开开发者模式）
  2. 运行「02-安装MSIX.ps1」（打印「安装成功！」）
  3. 系统设置 → 通知 → 允许通知访问；开始菜单启动「DSH 桌宠通知监听」
  4. 以后其它 App 的通知会被它读到并转给桌宠（桌宠气泡 + sounds\notify 提示音）
  卸载：运行「03-卸载MSIX.ps1」（证书保留，可再次安装）
  注意：证书是本机自签名（CN=DSH-Pet，有效期 5 年），只在自己机器上可信。
